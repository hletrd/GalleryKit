## Scheduled Findings

### C33-P1 - Metadata hardening for bulk alt suggestions and ID handling

Status: pending
Findings: AGG-C33-01, AGG-C33-07, AGG-C33-08
Files:

- `apps/web/src/app/actions/images.ts`
- `apps/web/src/lib/caption-generator.ts`
- `apps/web/src/__tests__/bulk-update-images.test.ts`
- `apps/web/src/__tests__/caption-generator.test.ts`

Plan:

- Sanitize copied alt suggestions with `sanitizeAdminString()` before writing to `title` or `description`.
- Enforce 255-code-point title and 5000-code-point description caps for copied suggestions.
- Skip invalid per-row suggestions rather than failing unrelated valid rows in the same bulk operation.
- Deduplicate validated IDs before applying the 100-image mutation cap.
- Truncate generated caption stubs by code points, not UTF-16 code units.
- Add regression tests for control characters, overlong suggestions, duplicate IDs, and surrogate-boundary truncation.
