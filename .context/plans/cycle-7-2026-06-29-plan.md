## Work Items

### 1. Fail closed on upload-time settings reads

Status: DONE
Findings: C7-01

Implementation:
- Split render-safe gallery config reads from ingest-strict config reads.
- Keep public rendering fallback behavior, but make browser upload and Lightroom upload return an error if settings cannot be read.
- Add focused coverage proving strict config rejects read failures while render config still falls back.

Validation:
- Gallery config and upload action/route tests.
- Full quality gates before commit.

### 2. Image processing derivative correctness

Status: DONE
Findings: C7-02, C7-10

Implementation:
- Base derivative sizing on fresh Sharp metadata width, not stale DB/caller width.
- Wait for every parallel derivative encoder to settle before cleanup and rethrow the first generation error.
- Add regression coverage for stale caller width and all-settled cleanup behavior where practical.

Validation:
- Process-image tests.
- Full quality gates before commit.

### 3. Canonical public filter and search failure behavior

Status: DONE
Findings: C7-03, C7-11

Implementation:
- Pass canonical server-filtered tags into `TagFilter`.
- Use canonical tags for active chip state, "All" state, and next URL toggle math.
- Return an HTTP error when semantic/similar search finds candidate IDs but metadata enrichment fails.
- Add focused tests for invalid URL tags and enrichment failure behavior.

Validation:
- Tag filter/client tests and semantic/similar route tests.
- Full quality gates before commit.

### 4. Queue durability and restart behavior

Status: DONE
Findings: C7-13, C7-14

Implementation:
- Persist upload-time processing settings for pending rows so restart bootstrap does not silently use later settings.
- Clear the persisted processing snapshot after successful processing or explicit failed-row retry as appropriate.
- Exclude durable failed rows from startup bootstrap until admin retry clears failure fields.
- Add migration, journal, reconcile, and queue regression coverage.

Validation:
- Migration/reconcile tests and image queue tests.
- Full quality gates before commit.

### 5. CLIP inference and upload preview responsiveness

Status: DONE
Findings: C7-07, C7-08

Implementation:
- Add a small process-wide CLIP inference limiter for real text/image inference, defaulting to concurrency 1 with an operator override.
- Add immediate lazy loading and async decoding for upload preview images.
- Leave larger preview virtualization/capping in the deferred register.

Validation:
- CLIP inference/source contract or focused limiter tests, upload preview tests/source checks.
- Full quality gates before commit.

### 6. Grid image fallback behavior

Validation:
- Grid image fallback tests.
- Full quality gates before commit.
