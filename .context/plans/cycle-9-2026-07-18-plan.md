## Acceptance criteria

- An in-flight detached config read that predates invalidation can return to
  its original caller but cannot repopulate the shared TTL cache or clear a
  newer in-flight owner.
- The first detached read after invalidation owns the refreshed cache; later
  calls dedupe onto it and observe the committed value without waiting two
  seconds.
- Main, timeline, year, and shared grid AVIF/WebP/JPEG `srcset` values include
  every configured normalized derivative exactly once and in ascending order.
- A valid `128,256,640,1536` configuration never strands its 640w/1536w files
  outside public grid markup; one- and two-size configurations remain valid.
- A one-item ultrawide DPR-2 gallery can select an existing derivative larger
  than 1536w (expected 4096w under the default ladder) instead of upscaling the
  truncated 1536w pair.
- Existing responsive slot sizes, intrinsic geometry, fallback behavior,
  scheduling, CDN resolution, and shared/archive/main candidate tests do not
  regress.
- `C6-24` is no longer listed as an open deferred row after its concrete race
  is fixed.
- Cycle 8 is archived with truthful signed-push/live-policy evidence and no
  invented production SHA.
- Every required gate is green without a new suppression.
