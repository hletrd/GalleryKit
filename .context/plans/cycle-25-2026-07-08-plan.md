- `apps/web/src/lib/admin-backfill-runner.ts`

Plan:

1. Add or reuse a strict uncached/detached gallery-config accessor that throws when `admin_settings` cannot be read.
2. Use that strict accessor in both color re-encode write paths before any row work or derivative encoding:

   - sidecar `backfill-color-pipeline.ts`
3. Update tests/source contracts so re-encode writers no longer depend on fail-open `getGalleryConfig()`/`getGalleryConfigDetached()` for byte-writing work.

- Upload/read-only pages can keep the existing documented fail-open behavior where appropriate.

Status: implemented. Added `getGalleryConfigDetachedStrict()` and moved both color re-encode writers to the strict accessor; source and behavior tests now pin the fail-closed path before encoding/version-bump work.

### WP3 - Add persistent admin form errors for category, tag, and SEO saves

Findings: `AGG-C25-21`

- `apps/web/src/app/[locale]/admin/(protected)/tags/tag-manager.tsx`

Plan:

1. Reuse the login/settings pattern: local `formError`/field-error state, persistent inline `role="alert"` messages, `aria-invalid`, `aria-describedby`, and focus recovery to first invalid field or alert.

Status: implemented. Category, topic-alias, tag, and SEO save failures now render persistent in-form alerts with `aria-invalid`/`aria-describedby` and focus recovery while retaining secondary toasts.
